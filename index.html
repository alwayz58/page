ตั้งค่าโปรไฟล์และการจัดเก็บบน GitHub

ระบบจะจัดเก็บโพสต์ในไฟล์ data/posts.json และอัปโหลดรูปภาพ/วิดีโอไว้ในโฟลเดอร์ media/
รองรับทั้ง Public และ Private Repository (ขนาดไฟล์ต่อชิ้นผ่านเบราว์เซอร์ไม่เกิน 25 MB)
วิธีเตรียม GitHub Repository และสร้าง Token แบบง่าย
  1. สร้าง Repository ใหม่บน GitHub (เลือกเป็น Private ได้เพื่อความเป็นส่วนตัว และติ๊ก Add a README file เพื่อให้มี Branch เริ่มต้น)
  2. ไปที่เมนู Settings ของบัญชี GitHub → Developer settings → Personal access tokens → Fine-grained tokens
  3. กด Generate new token เลือกเฉพาะ Repository ที่ต้องการ แล้วกำหนด Repository permissions หมวด Contents เป็น Read and write
  4. คัดลอกรหัส Token มาวางในช่องด้านบน แล้วกด "บันทึกและเชื่อมต่อ GitHub"
