เชื่อมต่อกับ alwayz-f304a-default-rtdb ให้อัตโนมัติแล้ว (เก็บแยกในโหนด /mypages_sync/ โดยไม่กระทบข้อมูลโปรเจกต์อื่นในฐานข้อมูล)
ทุกเครื่องที่ใส่ลิงก์ Cloud URL และรหัสห้องเดียวกัน จะเห็นโพสต์ รูปภาพ กลุ่มเนื้อหา และรายการบันทึกตรงกันอัตโนมัติภายในไม่กี่วินาที
ส่งข้อมูลจากเครื่องนี้ไปอุปกรณ์อื่น (ครบทั้งโพสต์ รูปภาพ กลุ่ม และที่บันทึกไว้) กดคัดลอกแล้วส่งข้อความไปทางแชทส่วนตัว (เช่น LINE Keep / แชทตัวเอง) เพื่อนำไปวางในมือถือหรือคอมอีกเครื่องได้ทันทีโดยไม่ต้องสมัครบัญชีใดๆ
ระบบจะรวมโพสต์และกลุ่มจากทั้งสองเครื่องเข้าด้วยกันโดยไม่ลบโพสต์เดิมที่มีอยู่
ผูกกับบัญชี alwayz58
จัดเก็บข้อความโพสต์ใน data/posts.json และไฟล์รูปภาพ/วิดีโอในโฟลเดอร์ media/ บน GitHub โดยอัตโนมัติ
วิธีสร้าง GitHub Token เพื่อจัดเก็บโพสต์ รูปภาพ และวิดีโอแบบง่าย
  1. เข้าบัญชี GitHub → กดรูปโปรไฟล์มุมขวาบน → Settings → เลื่อนลงล่างสุดเลือก Developer settings
  2. ไปที่ Personal access tokens → Tokens (classic) → Generate new token (classic)
  3. ติ๊กช่องสิทธิ์ repo แล้วกด Generate token จากนั้นคัดลอกรหัส ghp_... มาวางด้านบนแล้วกดบันทึกได้เลย (ระบบจะสร้าง Repo ให้อัตโนมัติหากยังไม่มี)
